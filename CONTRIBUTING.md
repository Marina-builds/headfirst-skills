# Contributing

HEADFIRST Skills are reviewed as executable workflows, not prompt collections.

Before proposing a Skill:

1. State its origin and list any upstream work.
2. Remove private data, customer-specific logic and local infrastructure identifiers.
3. Define its trigger, inputs, outputs and stop conditions.
4. Include at least one representative example or eval.
5. Record known limitations.

Changes that hide provenance or weaken a safety boundary will not be accepted.
