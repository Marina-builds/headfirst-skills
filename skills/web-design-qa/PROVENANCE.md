# Provenance

**Label:** REFERENCE-BASED REBUILD

This Skill was independently rewritten after studying [Hallmark](https://github.com/Nutlope/hallmark) at commit `2e1b9baaed5f1614c409ae7084c7d64f9e878344`.

The public reference contributed broad principles: inspect an existing system before judging it, audit before editing, avoid fabricated proof, verify responsive behavior in a rendered page, and study references without pixel cloning.

The HEADFIRST rebuild narrows the job to an evidence-backed QA layer for existing interfaces. It adds explicit Audit, Fix, Reference Study and Pre-launch modes; P0–P3 prioritization; Verified, Code-checked and Not verified evidence states; no-edit defaults; remote-reference safety; and boundaries with SEO, CRO and greenfield design work.

It does not redistribute Hallmark's theme catalog, macrostructures, CSS stamps, project logs, design-generation system, protected copy or assets. No identical substantive line from the pinned Hallmark `SKILL.md` is present in this package.
