# 给每个写动作单独划范围

用价格巡检做一次桌面演练。把「读取官网」「写入本次观察」「更新已接受的基准价」「通知客户」分成四行。假设任务只授权前两行，发现价格变化后，程序能留下证据和待审决定。再换成来源超时，检查它是否把本轮记录成未完成。

教学用示例，可复制后填入自己的记录。[打开配套材料](authority.csv)

## Decide who can authorize each write

Walk through a price check with permission to read the source and record an observation. Treat changing the accepted baseline and notifying customers as separate actions. Then simulate a timeout and check that the run records incomplete evidence.
