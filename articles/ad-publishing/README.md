# 用两个标签页验收删除草稿

用测试账户在两个标签页打开同一条未发布草稿。在第二页改一个字段并保存，回到第一页，先别刷新，试着删除。验收时看两个结果：刚保存的改动还在，第一页也能告诉你为什么这次删除没有完成。再分别换发布状态和账户，每次只改一个条件。

教学用示例，可复制后填入自己的记录。[打开配套材料](draft-cases.csv)

## Test draft deletion in two tabs

In a test account, open the same unpublished draft in two tabs. Save an edit in tab two, then try to delete from tab one without refreshing. Check both the surviving edit and the message shown to the user. Repeat with a changed publication state and with a different account, changing one condition at a time.
