# 把快查交给下一位研究者

假设同事给你三条公开广告，先问开头都在讲什么，随后改问下周应该测试哪个卖点。第一问可以按素材逐条标注。第二问要带过去的是原始广告、观察和范围，再补一项能区分卖点的测试。三条广告都没有转化数据，交接时就把这一栏留作未知。

教学用示例，可复制后填入自己的记录。[打开配套材料](handoff.md)

## Hand a quick scan to the next researcher

Start with three public ads. For a question about openings, annotate each ad. If the brief changes to choosing a selling point for next week, hand over the originals, your observations and the scope. Propose a test that can distinguish the claims. Leave conversion performance unknown when none of the ads supplies it.
