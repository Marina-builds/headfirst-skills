# 先给零值找一个对照

在配套表里，日级汇总能读到 9 次点击，细到广告单元的提取却返回空结果。两行是为练习准备的数据。交接时我会保留汇总行，在明细行写清提取失败，再把缺少访问权限的来源另记一行。这样下一位接手的人知道应该修提取、补权限，还是分析业务本身。

教学用示例，可复制后填入自己的记录。[打开配套材料](evidence.csv)

## Give a zero a cross-check

In the sample sheet the daily source contains nine clicks, but the ad-level extraction returns no rows. Keep the daily observation, mark the detailed extraction as failed and record any access gap separately. The next reviewer can then distinguish an extraction problem from a measurement or access problem.
