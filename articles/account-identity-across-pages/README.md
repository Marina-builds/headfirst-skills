# 同名账户怎么验

给两个测试账户都起名叫「推广」，分别关联青禾和远帆两个演示品牌。从列表抄下第一个账户显示的品牌名，到财务页搜索，再打开结果核对账户。最后把接口里的品牌列表字段去掉，模拟旧响应。页面要能打开，搜索结果和接口响应也要各查一次。

教学用示例，可复制后填入自己的记录。[打开配套材料](account-cases.csv)

## Test two accounts with the same name

Give two test accounts the same display name and assign one to each of two sample brands. Copy a brand from the list into finance search, open the result and check the account identity. Then omit the brand list from a test response to exercise the older format. Inspect the API response as well as the label on screen.
