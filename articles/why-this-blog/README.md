# 隔一天，凭这条记录重新做决定

用价格巡检做一条示例笔记。写下「人工已确认，程序价格仍旧」和下一步「检查基准价是否更新」。第二天只打开这条笔记，试着找到依据和待做的检查。如果唯一线索是聊天日期，就把那份能直接核对的记录补进来。

教学用示例，可复制后填入自己的记录。[打开配套材料](decision-note.md)

## Reopen the decision a day later

Write a sample decision note about a reviewed price whose stored value is still old. Next day, reopen just the note and try to locate both the evidence and the remaining baseline check. If a chat date is the only clue, add a reference someone can inspect directly.
