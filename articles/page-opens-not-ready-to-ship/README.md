# 拿一个按钮做一次移动端复验

从首页选一个主按钮，把窗口收窄，逐字对照按钮承诺和实际落点。记录入口、宽度、操作、看到的结果，再用键盘走同一路径。配套项目链接到我整理的 web-design-qa 清单，里面把内容真实性、操作层级和可访问性分开查。

公开 Skill 文件。[打开配套材料](skill-links.md)

## Retest one button on a narrow screen

Choose one primary action, narrow the viewport and compare the button promise with its actual destination. Record the entry URL, width, action and outcome, then repeat with a keyboard. The linked web-design-qa checklist covers content claims, task hierarchy and accessibility.
